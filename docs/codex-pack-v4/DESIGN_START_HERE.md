# Design Start Here

1. 브라우저에서 `design/index.html`을 연다.
2. `design/design.md`를 읽는다.
3. `design/design-tokens.json`을 코드 token으로 생성한다.
4. `design/mockups/*.png`의 정보구조와 geometry를 구현 기준으로 사용한다.
5. `design/ai-concept-boards/*.png`는 inspiration only로 취급한다.
6. 변경 시 `design/change-log.md`와 deterministic screenshot을 함께 갱신한다.
